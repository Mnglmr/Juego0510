# Aventura — V0.1

Primera versión jugable del proyecto de videojuego 2D de plataformas.

## Qué incluye V0.1

- Pantalla de inicio.
- Nivel 1 jugable.
- Movimiento izquierda/derecha.
- Salto y gravedad.
- Plataformas y colisiones.
- Cajas como obstáculos.
- 3 enemigos tipo "pibble" con movimiento básico.
- Sistema de 3 vidas.
- Cámara con desplazamiento horizontal.
- Teléfono como portal/meta del Nivel 1.
- Transición al terminar el nivel.
- Pantalla de "Nivel 2 en construcción".
- Diseño visual provisional en pixel-art mediante Canvas.

## Controles

- `A / D` o `← / →` — moverse.
- `W / ↑ / ESPACIO` — saltar.

## Cómo ejecutarlo

No necesita instalación ni servidor.

1. Descarga los archivos.
2. Abre `index.html` en el navegador.

También puedes subir los tres archivos a un repositorio de GitHub y activar GitHub Pages.
